What the benchmark measures

Frozen answer keys are written by a human labeller reading the live pages before seeing pipeline output. Verdicts on ambiguous cells are the labeller's and are bound to the exact shipped value judged — if a later run ships something else, the cell returns to CHECK rather than inheriting an old ruling. Key amendments happen only with a recorded, labeller-confirmed reason (3 to date).
